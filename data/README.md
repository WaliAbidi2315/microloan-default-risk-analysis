# Data

`synthetic_microloan_sample.csv` is generated by `src/generate_data.py`.

- 900 rows, 8 input features and 1 binary target
- 180 defaults (20%) and 720 repaid loans
- 24 missing `monthly_income` values and 14 missing `branch_distance_km` values
- `master_row_id` preserves the row identifier from the 3,000-row synthetic master dataset

No real borrower data is present. The simulation intentionally encodes the target using a hand-specified risk function; see the main README for interpretation and limitations.
