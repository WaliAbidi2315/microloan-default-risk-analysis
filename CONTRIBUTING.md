# Contributing

This repository is an educational portfolio project based on synthetic data.

1. Create a branch for your change.
2. Install dependencies with `pip install -r requirements.txt`.
3. Run `pytest -q` and `python src/train.py`.
4. Keep data-generation assumptions and evaluation methodology explicit.
5. Do not add real borrower information or present synthetic metrics as real-world lending evidence.

Please include a short explanation of methodological changes in pull requests.
